# 开发规则

## 勾选规则

- 每完成一个 TODO，必须更新 docs/refactor/TODO.md。
- 未验证的事项不得勾选。
- 用户要求未完成不用汇报，因此只在完成可验证事项后汇报。

## 修改规则

- 不破坏旧 app.py。
- 不删除旧 SQLite 数据。
- 新接口统一放在 /api/v1。
- 新模块尽量并行引入，减少返工。

## 专家协作规则

- 前端变更使用前端开发专家思路。
- 后端架构和 API 使用后端架构专家思路。
- MySQL schema、索引、迁移使用数据库优化专家思路。
- 需要外部代码助手时，可调用 Claude Code / Codex 辅助，但最终修改必须经过本项目测试。
