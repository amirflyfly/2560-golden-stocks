# 首板涨停次日上车固定量化模型

本模型用于把“当日首板涨停观察池”和“次日集合竞价/开盘确认上车”拆成两个阶段。T 日只生成观察候选，T+1 只有 `auction_confirmed` 才是纸面交易允许执行的买入信号。

## 交易规则前提

- 开盘集合竞价核心窗口为 9:15-9:25，其中 9:20 后撤单约束更严格，模型只把 9:20 后的竞价/开盘快照视为确认信号。
- 10cm、20cm、30cm 股票不能直接用涨幅比较，模型统一使用 `高开幅度 / 涨停幅度` 归一化。
- A 股普通股票存在 T+1 交易约束，因此竞价上车必须先过硬过滤和仓位约束。

规则参考：上交所交易规则修订说明、深交所交易规则、北交所交易规则：

- <https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml>
- <https://www.szse.cn/disclosure/notice/general/t20060515_499577.html>
- <https://www.bse.cn/jygl_list/200010919.html>

## T 日硬过滤

候选必须同时满足：

- `T 日收盘涨停`，且过去 `no_limit_up_lookback` 个交易日无涨停。
- 剔除 ST、退市、停牌、非股票；默认剔除北交所，科创板可配置。
- 成交额、换手率、20 日成交额比率达到最低要求。
- 剔除一字缩量板、过度放量但收盘不强的烂板。
- 市场情绪低于阈值时降低评分并加风险标签。

## T 日预选评分

满分 100：

- 大盘情绪 15：上涨家数占比、涨停/跌停数量、MA20 上方比例。
- 板块强度 20：行业或板块分组涨停数、上涨比例、平均涨幅。
- 涨停质量 25：是否收在涨停价附近、收盘位置、量能是否适中、是否一字。
- 量能流动性 15：成交额、成交额/20 日均值、成交量/20 日均值、换手率。
- 股性 15：历史涨停后次日高开率、收涨率、连板率、次日冲高表现。
- 事件风险 10：缺失涨停规则、短线过热、高波动、换手缺失等风险扣分。

默认 `preselect_score >= 70` 才进入观察池。

## T+1 集合竞价确认

模型读取本地实时快照中的 `open/prev_close/last_price/volume/amount`，在没有专用竞价字段时将其作为 9:25 附近快照的近似输入。

确认条件：

- `open_gap / limit_rate` 位于 `0.20-0.75`，即主板约 +2% 至 +7.5%。
- 快照成交额不低于 T 日成交额的 3%，且不低于配置的最小金额。
- 快照成交量不低于 T 日成交量的 3%。
- 快照价格相对开盘价没有明显塌陷。
- 竞价确认分 `auction_score >= 70`。

最终评分：

`final_score = 0.6 * preselect_score + 0.4 * auction_score`

## 输出信号

- `preopen_watch`：T 日首板预选通过，等待次日竞价确认，只观察不买。
- `auction_confirmed`：T+1 竞价/开盘快照通过确认，可进入纸面交易买入流程。
- `auction_rejected`：竞价不满足上车条件，默认不输出；配置 `include_rejected=True` 可用于复盘。

## 风控执行

- 纸面交易只允许 `FIRST_LIMIT_UP + auction_confirmed` 触发买入。
- `preopen_watch` 会被跳过，跳过原因为 `first_limit_up_auction_pending`。
- `auction_rejected` 会被跳过，跳过原因为 `first_limit_up_auction_rejected`。
- 生产环境仍需本地快照和历史 K 线，不使用 mock/fallback 行情做实盘信号。

本策略只生成量化信号和推荐理由，不构成收益承诺或人工买卖建议。
