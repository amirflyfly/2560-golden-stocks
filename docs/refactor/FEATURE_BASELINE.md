# 当前功能基线

## 当前技术形态

- 后端：Flask
- 前端：Jinja 模板 + 局部 React/Vite K 线图
- 数据库：SQLite data/picks.db
- 数据源：AkShare / mock

## 当前核心功能

- 每日选股记录管理
- 2560 战法策略
- 首板涨停策略
- 多策略扫描
- 股票历史行情与 K 线展示
- 策略池管理
- 回测结果记录
- 研究报告
- 后台管理
- 用户与 session 表

## 重构期间保护规则

- 旧入口 app.py 保持可启动。
- 旧 SQLite 不直接破坏。
- 新 API 使用 /api/v1 前缀。
- 新数据模型先并行建立，再迁移读写。
- 每个迁移阶段必须可回退。
