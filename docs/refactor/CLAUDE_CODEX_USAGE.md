# Claude Code 与 Codex 协作约定

## 使用原则

本项目后续开发可以调用本机已安装的 Claude Code 和 Codex 辅助分析、生成或评审，但主线修改必须遵守项目 TODO 与架构文档。

## 适合交给外部编码助手的任务

- 大范围代码搜索和重构建议
- 前端组件迁移草案
- SQLAlchemy model 初稿检查
- mootdx provider 异常路径评审
- 测试用例补全建议

## 不直接交给外部助手决定的事项

- 架构边界变更
- 数据库租户隔离策略
- 删除旧代码
- 生产配置和密钥
- 数据迁移执行

## 合并要求

- 外部助手产物必须经过人工或主流程复核。
- 不允许未验证代码直接替换旧功能。
- 每项完成后必须更新 docs/refactor/TODO.md。
